⚙️ Prerequisites
Before running any script or program in this repository, make sure your computer has the following installed:

Python (Version 3.8 or later)

Visual Studio Code (VS Code)

Python Extension for VS Code

🚀 Installation & Usage Steps
1. Copy (Clone) Repository
Open a terminal/command prompt and run the following command:

Bash
git clone [https://github.com/marshasabela842/praktikum-pythoncaca.git](https://github.com/marshasabela842/praktikum-pythoncaca.git)
2. Go to Project Folder
Bash
cd praktikum-pythoncaca
3. Create & Activate Virtual Environment (Optional but Recommended)
Windows:

Bash
python -m venv venv
venv\Scripts\activate
macOS / Linux:

Bash
python3 -m venv venv
source venv/bin/activate
4. Install Dependencies / Libraries
Install all required libraries (including coloramaand other supporting libraries) by running:

Bash
pip install -r requirements.txt
💻 How to Run the Program
Select the Python file you want to run, then execute it via the terminal:

Bash
python nama_file.py
🛠️ Libraries Used
Colorama: Used to color the text output in the terminal.
